# Браузерный вход через Playwright

## Как работает

1. `python -m itmo_local browser login` открывает отдельное окно Edge или
   Chrome (согласно `BROWSER_CHANNEL`). Войдите в ITMO.ID вручную и откройте
   «Расписание»; приложение ждёт ответа персонального API до 10 минут.
2. `python -m itmo_local browser check` использует тот же профиль в
   headless-режиме, получает 105-дневный диапазон и печатает только агрегаты.
   Ни SQLite, ни iCloud не изменяются.
3. `sync-itmo` валидирует полученные данные и записывает их **только** в
   локальную SQLite.
4. `icloud preview` читает и сравнивает события. `icloud push` применяет
   изменения к ранее привязанному отдельному календарю.

В фоновом режиме приложение наблюдает только HTTPS-запрос
`https://my.itmo.ru/api/schedule/schedule/personal` и отправляет до
четырёх дополнительных авторизованных GET на **тот же хост и путь**, меняя
только даты; прочие параметры самого сайта сохраняются. Редиректы
дополнительных запросов отключены. Каждый запрошенный день должен
присутствовать в ответе. Несовпадение перекрывающихся ответов блокирует
всю синхронизацию.

Подробнее о диапазонах: [BROWSER_MONTHS_0_4.md](BROWSER_MONTHS_0_4.md).

## Чего программа не делает

Она не собирает пароль ИТМО, не копирует токены/cookies в свои файлы,
не создаёт HAR, не обходит MFA, CAPTCHA или rate limiting. Это
**неофициальная** автоматизация сайта, а не гарантированное публичное API.
Правила университета могут запрещать её; при блокировке нельзя
обходить ограничения.

## Типичные ошибки

- `browser_launch_failed_check_edge_or_profile_lock`: браузер
  недоступен, профиль занят или проблема с правами. Закройте окно,
  созданное программой (не обязательно закрывать обычный Edge), и повторите.
- `browser_no_schedule_response_login_or_site_navigation_required`:
  выполните `browser login` и вручную откройте раздел расписания.
- `browser_session_rejected_by_itmo`: сессия истекла или доступ отклонён.
  Повторите обычный вход через официальный сайт.
- `browser_schedule_not_json` / `browser_schedule_schema_changed`:
  структура сайта изменилась; старый календарь не затрагивается.
- `browser_expanded_date_coverage_incomplete`: хотя бы один день
  отсутствует в ответе, поэтому публикация запрещена.
- `browser_schedule_rate_limited`: прекращайте повторные запросы,
  соблюдайте ограничения сервиса.

Сохранённый профиль может содержать активные cookies и другие
чувствительные данные. Не передавайте его другим и не размещайте в
синхронизируемых или общедоступных папках.
