# Установка на Windows: от нуля до первого занятия в iPhone

## Требования

- Windows 10/11 x64, **Python 3.12 или 3.13 x64**; Edge или Chrome; интернет.
- Личный доступ к **my.itmo**, возможность войти через ITMO.ID.
- Учётная запись Apple с включённым iCloud Calendar и возможностью сгенерировать **app-specific password**.
- Пользователь Windows с правом создавать свои задачи в Task Scheduler (обычно права администратора не требуются).
- Применимые правила и разрешения ИТМО должны позволять такую автоматизацию; проект не официальный.

## 1. iCloud: отдельный пустой календарь

Открой [iCloud Calendar](https://www.icloud.com/calendar/) и создай **новый пустой календарь** с именем, например, `ITMO` (латинские буквы). Не переименовывай готовый календарь с личными событиями и не указывай его имя в приложении. Имена различаются по регистру и языку: `ITMO` и `ИТМО` — разные строки.

На [account.apple.com](https://account.apple.com/) создай **пароль для приложения**. Не вводи обычный пароль Apple Account в нашу программу. Пароль приложения нужен для CalDAV и может обладать более широким доступом, чем только к календарю ИТМО. Никому его не пересылай.

На iPhone включи синхронизацию календарей iCloud и отображение нового календаря `ITMO`.

## 2. Установка Python

Установи [Python 3.12 или 3.13, Windows installer (64-bit)](https://www.python.org/downloads/windows/), с `Add python.exe to PATH` или `py` launcher. В PowerShell проверь:

```powershell
py -3.12 -V
```

Или `py -3.13 -V`. Путь вроде `C:\Users\...\AppData\Local\Programs\Python\...` допустим. Система не поддерживает Python 3.11/3.14 в качестве проверенной установки.

## 3. Скачивание и первичная конфигурация

Скачай **Windows ZIP из GitHub Releases**, а не архив предыдущего патча. Распакуй в `C:\Apps\itmo-calendar-local` или другую обычную папку вне OneDrive. **Не запускай скрипты прямо внутри ZIP.**

Запусти `SETUP.cmd` двойным кликом. Установка создаёт `.venv` только для приложения и установит библиотеки через `pip`. При первом запуске спросит:

- Apple Account email (не пароль);
- точное имя **пустого** iCloud календаря (`ITMO`);
- `msedge` (рекомендуется) или `chrome`.

Эти значения сохраняются в локальный `.env`, который Git игнорирует. При повторном `SETUP.cmd` он **не перезаписывается**. Пароль Apple и пароль ИТМО в `.env` **не записываются**.

Если Windows показывает предупреждение SmartScreen, проверяй происхождение архива и исходники скрипта, а не отключай защиту системы глобально. В репозитории нет подписанного `.exe`; это открытый Python/PowerShell-проект.

## 4. Мастер подключения

Запусти `FIRST_RUN.cmd`:

1. Введи **пароль приложения Apple** в скрытом терминальном запросе: он сохранится через Windows DPAPI в профиле этого пользователя Windows.
2. Мастер найдёт календарь по его **точному имени**. Если календарь не пуст, привязка запрещена. Напечатай `BIND` только после проверки, что указан именно пустой отдельный календарь.
3. В отдельном профиле Edge/Chrome откроется официальный сайт ИТМО. Войди через ITMO.ID, при необходимости пройди MFA, открой «Расписание». Окно закроется, когда ответ расписания получен.
4. Программа получит примерно 105 дней, сохранит данные в SQLite, покажет количество `CREATE`, `UPDATE`, `DELETE` и `UNCHANGED`. Само расписание в терминал и логи не печатается.
5. Сверь число и даты занятий с my.itmo. Только если согласен, **введи `PUBLISH`**. Если просто закроешь окно или введёшь другое слово, запись в iCloud не произойдёт.
6. Убедись, что события появились на iPhone. При желании включи автосинхронизацию при входе в Windows и в 07:00, 12:00, 18:00, 23:00 (локальное время Windows).

**Не повторяй `icloud push` вслепую после сетевой ошибки**: сначала сделай `icloud check` и `icloud preview`, чтобы увидеть частично записанные события.

## 5. Повседневное использование

При нормальной работе ничего делать не нужно. Для ручного запуска используй `RUN_NOW.cmd`. Чтобы прочитать статус — `STATUS.cmd`. Если Windows была выключена несколько дней, синхронизация возобновится при следующем разрешённом запуске. Когда истечёт сессия ITMO.ID, нужно снова вручную выполнить:

```powershell
.\.venv\Scripts\python.exe -m itmo_local browser login
```

Не пытайся переносить cookies, DevTools HAR или пароли в Python для обхода повторного входа.

## 6. Обновление приложения

1. Останови запущенные `run` / `browser check`, закрой только профиль браузера, созданный программой.
2. На всякий случай сделай **консистентную** копию SQLite командой `python -m itmo_local backup C:\...\backup.sqlite3` в личную защищённую папку (эта копия тоже содержит расписание).
3. Скопируй файлы **из нового ZIP поверх** предыдущих в той же папке. **Не удаляй** `.env`, `.venv` или `%LOCALAPPDATA%\PersonalItmoCalendar`.
4. Запусти `SETUP.cmd` для обновления библиотек. Существующие настройки сохранены.
5. Проверь `STATUS.cmd`, затем при желании `browser check` и `icloud preview`.

При изменении пути установки обнови задачу планировщика через `register-task.ps1`. **Не запускай две установки с разными планировщиками одновременно**.

## 7. Отключение и удаление

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\unregister-task.ps1
```

Это удалит только задачу Task Scheduler. Чтобы удалить приложение — после остановки задач удали каталог установки. По желанию вручную удали `%LOCALAPPDATA%\PersonalItmoCalendar` (там находятся SQLite, браузерная сессия и DPAPI-файлы; удаление необратимо). Удаление локальных файлов **не удаляет** события iCloud и **не отзывает** сессии. Если хочешь полностью прекратить использование, вручную удали выделенный календарь `ITMO` на iCloud.com, отзови app-specific пароль в Apple Account и заверши университетские сеансы через официальный сайт.

## Примечания

- Это ПО для **одного** локального пользователя Windows: запуск под `SYSTEM` не поддерживается (DPAPI привязан к учётной записи).
- iCloud-синхронизация с телефоном не мгновенная; программа не может обновляться, когда ноутбук выключен.
- Playwright держит отдельный локальный профиль браузера. Даже если обычный Chrome уже открыт, приложение **не** вставляет вкладку в его обычный профиль.
- Если my.itmo меняет структуру API или ограничивает автоматизацию, программа прекращает обновление. Мы не рекомендуем обходить эти ограничения.
