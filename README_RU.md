# ITMO Calendar Local

**Неофициальная, бесплатная синхронизация персонального расписания my.itmo с календарём iPhone через iCloud. Без VPS и платной подписки.**

> **Статус: публичная бета v0.5.1.** Поддерживается Windows 10/11 и Python 3.12/3.13 (64-bit). Требуются iCloud, приложение «Календарь» на iPhone и установленный Microsoft Edge или Google Chrome. Это **не** приложение от ИТМО или Apple. Автоматизация браузера может быть ограничена правилами университета; до использования убедитесь, что она разрешена.

**[English](README.md)** · [Подробная установка](docs/SETUP_WINDOWS_RU.md) · [Решение проблем](docs/FAQ_RU.md) · [Безопасность](SECURITY.md)

## Что умеет

- Загружает **твоё** расписание из my.itmo после ручного входа через официальный ITMO.ID.
- Обновляет даты примерно за **14 дней назад и 90 дней вперёд** (105 дней включительно), объединяя четыре запроса на непересекающиеся полные недели.
- Создаёт, изменяет и удаляет пары в **отдельном, заранее созданном и пустом** календаре iCloud; другие календари не меняет.
- Сохраняет UID событий, чтобы не создавать дубликаты при повторной синхронизации.
- По желанию запускается при входе в Windows и в 07:00, 12:00, 18:00 и 23:00 по времени Windows.
- При истёкшей авторизации, неполном ответе или блокировке API не удаляет старое расписание.
- Не требует вводить пароль ИТМО в программу: вход происходит в отдельном профиле Edge/Chrome. Пароль приложения Apple хранится локально через Windows DPAPI.

## Быстрый старт

<details>
<summary>Перед установкой</summary>

1. Установи [Python 3.12 или 3.13 для Windows, x64](https://www.python.org/downloads/windows/) и включи «Add python.exe to PATH» либо установи Python Launcher (`py`).
2. Убедись, что Edge или Chrome установлен.
3. Войди на [icloud.com/calendar](https://www.icloud.com/calendar/) и **создай новый пустой календарь**, например `ITMO` (латиницей). Имя должно точно совпадать с настройкой приложения.
4. На [account.apple.com](https://account.apple.com/) подготовь **пароль для приложения (app-specific password)**, а не основной пароль Apple Account.
5. В iPhone включи iCloud Calendar и отображение нового календаря.

</details>

1. Открой вкладку **Releases** в GitHub и скачай ZIP `itmo-calendar-local-v0.5.1-windows.zip`. Распакуй в обычную папку, например `C:\Apps\itmo-calendar-local` (не в OneDrive).
2. Двойным кликом запусти **`SETUP.cmd`**. Установщик создаст `.venv`, установит Python-библиотеки и спросит Apple ID, точное имя календаря и Edge/Chrome. **Администратор не требуется**. Файлы и пароли от предыдущей установки не перезаписываются.
3. Двойным кликом запусти **`FIRST_RUN.cmd`**. Мастер поможет сохранить пароль приложения Apple в DPAPI, привязать пустой календарь, войти через ITMO.ID, проверить расписание и вывести **предварительный план изменений**. Запись в iCloud произойдёт **только** после явного ввода `PUBLISH`.
4. Сверь занятия на iPhone. Если всё правильно, разреши мастеру настроить расписание обновлений Windows.

> **Важно:** Python сам не устанавливается через SETUP.cmd. Если Python отсутствует, установщик подскажет, откуда его взять. Первый запуск требует интернета и ручного входа в ITMO.ID.

## Ручное управление (PowerShell в папке проекта)

```powershell
# Только прочитать источник, не меняя локальную базу или iCloud
.\.venv\Scripts\python.exe -m itmo_local browser check

# Загрузить расписание в локальную базу
.\.venv\Scripts\python.exe -m itmo_local sync-itmo

# Посмотреть, что БЫЛО БЫ изменено в iCloud (только чтение)
.\.venv\Scripts\python.exe -m itmo_local icloud preview

# Записать изменения в ранее привязанный календарь iCloud
.\.venv\Scripts\python.exe -m itmo_local icloud push

# Один полный цикл: my.itmo -> SQLite -> iCloud
.\.venv\Scripts\python.exe -m itmo_local run

# Статус без вывода паролей и названий занятий
.\.venv\Scripts\python.exe -m itmo_local status

# Истёк сеанс ИТМО? Открой окно для повторного входа
.\.venv\Scripts\python.exe -m itmo_local browser login
```

Также можно двойным кликом использовать `RUN_NOW.cmd` и `STATUS.cmd`.

**Автоматическое обновление** выполняется только при работающем ноутбуке с активной Windows-сессией. Обновления на iPhone зависят также от синхронизации iCloud. Обновление не происходит в реальном времени и не гарантируется, если ИТМО меняет сайт или блокирует автоматические обращения.

## Безопасность и приватность

Никогда не публикуйте `.env`, `%LOCALAPPDATA%\PersonalItmoCalendar`, `itmo-browser-profile`, файлы `*.dpapi` и `*.sqlite3`, HAR-файлы или содержимое вкладки Network браузера. В профиле могут быть действующие университетские cookies, а в SQLite — личное расписание. Секреты не должны попадать в GitHub Issues или Pull Requests. См. [SECURITY.md](SECURITY.md).

Программа не обходит CAPTCHA, MFA, ограничения ITMO.ID или rate limit. Доступ к своему расписанию осуществляется через обычную авторизованную сессию сайта. При отказе сервера программа прекращает синхронизацию. Возможность автоматизировать использование сервиса может регулироваться правилами ИТМО.

## Удаление и обновление

Обновить: скачай новый релиз, скопируй файлы **поверх установленной версии**, не удаляя `.env`, `.venv` и папку пользовательских данных в AppData. В папке проекта запусти `SETUP.cmd` для обновления библиотек. Для планировщика Windows путь установки должен остаться прежним.

Выключить автосинхронизацию:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\unregister-task.ps1
```

Удаление приложения **не удаляет события iCloud автоматически**. Отдельный календарь можно удалить вручную из iCloud, а пароль приложения — отозвать в Apple Account. Подробнее: [установка, обновление и удаление](docs/SETUP_WINDOWS_RU.md).
